# AI Use

We used Claude (Anthropic) as a coding and analysis assistant on this project, within the
course policy on LLM use.

**What Claude helped with.**
- Writing and debugging code to our specifications.
- Finding bugs in the shared data pipeline.
- Running experiments we specified and tabulating their results.
- Helping frame results so that we could efficiently interpret the outcomes of our experiments.

We are responsible for everything submitted and have confirmed every result ourselves.
